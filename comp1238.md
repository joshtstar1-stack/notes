# COMP1238 - Introduction to Data Management

My study notes for the first five weeks of COMP1238 at George Brown College.

## Week 1 - History
- Writing systems allow people to record and share information.
- One writing system can be used to represent multiple languages.
- Cuneiform was one of the earliest writing systems.

## Week 2 - Bits and Bytes
- A bit is the smallest unit of digital information and can represent 0 or 1.
- One byte contains 8 bits.
- Computers use binary numbers to represent and process information.

## Week 3 - Text and Data
- ASCII is a character encoding system that represents letters, numbers, and symbols.
- Unicode supports characters from many languages and writing systems.
- Markdown uses simple symbols to format headings, lists, and links.

## Week 4 - Files and GitHub
- Git is a version control system used to track changes to files.
- GitHub allows users to store repositories and collaborate on projects.
- A commit saves a recorded change in a repository's history.

## Week 5 - Command Line and File Management
- The command line allows users to interact with a computer using text commands.
- Files and directories are organized using paths.
- Relative paths describe locations starting from the current directory.
